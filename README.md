# Deloitte Data Analytics Virtual Internship

This repository contains my completed project files for the Deloitte Data Analytics Virtual Internship hosted on Forage. 

The internship simulates real-world data analytics challenges faced by Deloitte consultants, focusing on operations optimization and corporate compliance.

---

## 📈 Task 1: Telemetry Data Analysis

* **Objective:** Analyze massive machine sensor telemetry datasets to pinpoint operational inefficiencies and factory downtime errors.
* **Key Insights:** Identified critical hardware failure patterns and localized specific operational bottlenecks at the `daikibo-factory-seiko` facility.
* **Deliverables:** 
  * 📊 **Tableau Dashboard:** `deloitte task 1.PNG` (Visual tracking of unhealthy device downtimes per factory and device type)
  * 📁 **Raw Dataset:** `daikibo-telemetry-data.csv` (The underlying sensor telemetry log)

---

## 📊 Task 2: Pay Equality Investigation

* **Objective:** Audit corporate compensation architecture to isolate gender or role-based wage gaps and organizational inequalities.
* **Key Insights:** Engineered a comparison matrix to classify employee organizational roles into distinct compliance bands (*Fair*, *Unfair*, and *Highly Discriminative*).
* **Deliverables:**
  * 🗃️ **Analysis Sheets:** `Task 2 Equality Table.xlsx` & `Task 2 answer.xlsx` (Cleaned data tables highlighting statistical pay disparities)
